# Naizabeth Bermudez · Portfolio (Vite + TypeScript + Tailwind)

    npm install
    npm run dev      # desarrollo
    npm run build    # producción (carpeta dist/)

## Estructura
- `src/data/portfolio.ts`       → todos los textos/datos (edita aquí tu CV)
- `src/components/*.ts`         → una sección por archivo (`renderX()`)
- `src/effects/neuralCanvas.ts` → partículas de fondo
- `src/utils/ui.ts`             → helpers (chips, cabeceras de sección)
- `src/main.ts`                 → ensambla la página e inicializa interacciones
